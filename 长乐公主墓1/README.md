# 长乐公主墓数字考古网站（首页原型）

这是按 1920×1080 首页设计稿写出的 React + Vite 第一版。

## 启动

```bash
npm install
npm run dev
```

Vite 默认会输出本地访问地址，通常是：

```text
http://localhost:5173
```

## 当前已完成

- 顶部固定导航
- 1920×1080 主视觉
- 长乐公主墓 Hero 文案
- “进入墓室 / 浏览壁画”按钮
- 右侧 3 个悬浮知识入口
- 4 个底部专题卡片
- “古董眼光 / 考古眼光”交互切换
- 响应式移动端布局
- 下一阶段人物页占位区
