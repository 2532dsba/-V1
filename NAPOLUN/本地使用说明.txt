走陵网站 V1｜本地使用说明

启动网站：
1. 双击“启动走陵网站.bat”。
2. 首次运行会自动准备网站所需组件，请保持网络连接。
3. 浏览器会自动打开网站；如果 5173 已被占用，会自动选择其他可用地址。
4. 需要关闭网站时，直接关闭运行窗口即可。

生成正式部署文件：
1. 在当前文件夹空白处右键，选择“在终端中打开”。
2. 输入 npm install
3. 输入 npm run build
4. 生成的 dist 文件夹即为正式部署文件。

注意：
- 请保留 public 文件夹，其中包含首页视频、音乐和字体。
- 修改源码后，运行窗口会自动刷新网页。

部署到 Vercel：
1. 双击“部署到Vercel.bat”。
2. 首次使用时，按照窗口提示登录或注册 Vercel。
3. 选择 1 会生成预览网站，选择 2 会发布正式网站。
4. 首次创建项目时，Vercel 的项目设置使用自动识别的 Vite 默认值即可。
5. 部署完成后，窗口中会显示可公开访问的 vercel.app 地址。

项目根目录已经包含 vercel.json，独立页面 /mausoleums 可直接访问和刷新。
